# Отчёт по домашнему заданию OTUS: мультимодальный Omni Assistant

## Цель и реализация

Собран мультимодальный голосовой ассистент: **аудиовопрос → Whisper base (локально, CPU) → Qwen3.6-35B (Yandex AI Studio, изображение + текст) → Silero TTS v5_ru / aidar (локально, CPU) → голосовой WAV**. Создан веб-интерфейс Gradio и функция `run_omni_assistant(image, audio_query)` с замерами ASR/VLM/TTS/TOTAL.

**Отклонение от ТЗ:** локальная Qwen3-VL-4B/8B с 4-битным квантованием не использована; вместо неё — облачная Qwen3.6-35B. Причина — ограничения локального оборудования. Дополнительного алгоритма шумоподавления перед Whisper нет: воздействие шума специально изучалось экспериментально.

| № | Тест | Наблюдение |

| 1 | Обычный вопрос о холодильнике | Ассистент предложил блюда; в одном из ранних ответов добавил неподтверждённые продукты |

## Ключевые инженерные наблюдения

1. Сквозной пайплайн работает, но последовательная архитектура заставляет ждать завершения каждого этапа.
2. Повреждение текста на ASR иногда компенсируется общим контекстом задачи и изображением, но не всегда. Без контрольного сравнения «только текст» нельзя утверждать, что именно изображение восстановило намерение.
3. Whisper base на CPU может работать заметно дольше при отдельных вопросах. Замеры разовых запусков недостаточны для оценки стабильной задержки.
4. Во время одного из ранних запусков ответ Qwen прерывался по `max_output_tokens`; после изменения лимита и режима reasoning ответ завершился, но параметры менялись одновременно, поэтому причинный эффект каждого не установлен.
5. Исправлена перезапись WAV: новый запрос создаёт отдельное имя с UUID. Есть независимые WAV для финальных экспериментов.
6. WER честно оставлен неопределённым без проверенного вручную эталона. Объективный бенчмарк из нескольких изображений также недостаточен для обобщения на другие задачи.

## Готовность к практическому использованию

**Для учебной демонстрации — да. Для разговорного ассистента в реальном времени — пока нет.** Следующие улучшения: ASR на более производительном устройстве или с потоковой обработкой, VAD и сегментация, отдельное подавление шума, повторный запрос при низкой уверенности ASR, кеширование, потоковый TTS/ответ, измерение нескольких прогонов и WER на размеченном наборе, мониторинг стоимости облачной модели.

## Воспроизведение

Инструкции запуска в `README.md`. В Notebook можно без API-ключа просмотреть сохранённые испытания и проиграть входное и выходное аудио. Дополнительный живой запуск ассистента требует доступа к Yandex AI Studio и локального кэша Silero.
